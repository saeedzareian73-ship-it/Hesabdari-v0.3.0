دفتر حساب - نسخه ۰.۳.۱ (اندروید)
==============================

نوع برنامه: وب‌اپلیکیشن قابل نصب (PWA) برای Android و قابل اجرا روی کامپیوتر.

امکانات نسخه ۰.۳.۱ (بر پایه نسخه ۰.۳):
- حساب‌های کاری مستقل، مشتریان، کالاها، فاکتورها، دریافت‌ها، هزینه‌ها و گزارش‌ها
- مدیریت موجودی با واحد پایه و تبدیل واحدهای دلخواه
- ورودی تعداد و مبلغ به‌صورت عدد صحیح و بدون اعشار
- انتخاب تاریخ شمسی از تقویم، بدون نیاز به تایپ تاریخ
- دکمه بازگشت در نوار بالا؛ دکمه Back مرورگر نیز بین صفحه‌های قبلی حرکت می‌کند
- مرتب‌سازی موجودی کالاها بر اساس تعداد بیشتر، تعداد کمتر یا نام الفبایی
- خروجی Excel، چاپ/PDF و فایل پشتیبان JSON
- اتصال اختیاری به Firebase برای همگام‌سازی و پشتیبان ابری هنگام اجرای برنامه و پس از ذخیره تغییرات
- امکان مجاز/غیرفعال کردن کاربران ابری از طریق Firebase Console

اجرای آزمایشی روی کامپیوتر:
۱) ZIP را استخراج کنید.
۲) در پوشه hesabdari_mobile، PowerShell یا Terminal را باز کنید.
۳) اجرا کنید: python -m http.server 8000
۴) در مرورگر باز کنید: http://localhost:8000

نصب روی گوشی Android:
۱) پوشه برنامه را روی یک میزبان HTTPS (مثل GitHub Pages) منتشر کنید.
۲) آدرس HTTPS را با Chrome گوشی باز کنید.
۳) منوی سه‌نقطه > Install app یا Add to Home screen را انتخاب کنید.

تقویم شمسی:
- در فیلدهای تاریخ، دکمه «تقویم» را بزنید و روز موردنظر را انتخاب کنید.
- تاریخ‌ها در داخل برنامه به شکل استاندارد ذخیره می‌شوند و در گزارش‌ها شمسی نمایش داده می‌شوند.

اعداد:
- تعداد کالا، ضریب واحد، قیمت، تخفیف، دریافت و هزینه فقط عدد صحیح می‌پذیرند.
- اعشار برای این نسخه لازم نیست و ورودی‌ها هنگام تایپ به عدد صحیح تبدیل می‌شوند.

مرتب‌سازی انبار:
- از فهرست موجودی، انتخاب کنید: تعداد بیشتر به کمتر، تعداد کمتر به بیشتر یا ترتیب الفبایی.
- انتخاب شما برای همان کسب‌وکار ذخیره می‌شود.

پشتیبان دستی:
- از «بیشتر ← پشتیبان و خروجی» فایل JSON بگیرید.
- برای انتقال به دستگاه دیگر، فایل را در دستگاه جدید بازیابی کنید.
- خروجی Excel برای گزارش و تحلیل است؛ برای بازیابی کامل از JSON استفاده کنید.

فضای ابری:
- همگام‌سازی ابری در صورت تکمیل firebase-config.js و راه‌اندازی Firebase فعال می‌شود.
- در آغاز برنامه و پس از هر ذخیره (تا وقتی برنامه باز است) همگام‌سازی انجام می‌شود؛ زمان‌بندی پس‌زمینه یا Cloud Functions لازم نیست.
- برای تنظیم کامل، فایل «راه‌اندازی-فضای-ابری.txt» را دنبال کنید.
- تا قبل از تکمیل تنظیمات، برنامه فقط روی همین دستگاه ذخیره‌سازی می‌کند.
- برای هر حساب مجاز، سند access/{UID} با فیلد enabled=true در Firestore ایجاد کنید. برای قطع دسترسی، آن را false کنید.
- هرگز GitHub Personal Access Token یا رمز عبور را با دیگران به اشتراک نگذارید؛ برای GitHub فقط از OAuth خود برنامه استفاده کنید.

مهاجرت از نسخه ۰.۲:
- نسخه جدید را دقیقاً روی همان آدرس HTTPS قبلی منتشر کنید تا IndexedDB همان مبدأ حفظ شود.
- پیش از بروزرسانی، از نسخه قبلی فایل JSON پشتیبان بگیرید.
- برای نسخه PWA، Service Worker به‌روزرسانی می‌شود؛ اگر نسخه قدیمی ماند، Chrome را کاملاً ببندید و دوباره باز کنید یا یک‌بار صفحه را تازه‌سازی کنید.

درباره برنامه:
این برنامه با هدف ساده‌تر کردن حسابداری برای کسب‌وکارهای کوچک و متوسط طراحی و توسعه داده شده است. من سعید ، توسعه‌دهنده مستقل، تلاش کرده‌ام تجربه‌ای ساده، سریع و کاربردی بسازم. نظرات و پیشنهادهای شما به بهبود برنامه کمک می‌کند.
آیدی تلگرام: Saeedzaran


به‌روزرسانی نسخه ۰.۳.۱:
- کش Service Worker نسخه‌بندی شده است و فایل‌های اصلی هنگام باز شدن برنامه ابتدا از شبکه تازه‌سازی می‌شوند و در حالت آفلاین از نسخه ذخیره‌شده استفاده می‌شود.
- فایل firebase-config.js دیگر از کش قدیمی به‌صورت مستقیم تحویل داده نمی‌شود؛ در صورت نبود اینترنت، نسخه ذخیره‌شده فقط fallback است.
- داده‌های حسابداری در IndexedDB نگهداری می‌شوند؛ این به‌روزرسانی دیتابیس محلی را حذف یا بازنشانی نمی‌کند.
- برای انتشار نسخه‌های بعدی، مقدار CACHE_NAME در sw.js را افزایش دهید تا Service Worker جدید نصب و کش قدیمی برنامه جایگزین شود.
